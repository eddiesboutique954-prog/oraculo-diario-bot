Política de Privacidad de Oráculo Diario

Última actualización: 12 de noviembre de 2026

Esta aplicación ("Oráculo Diario") es una herramienta automatizada de publicación de contenido de tarot y astrología en YouTube.

1. Información que recopilamos

Oráculo Diario únicamente accede a la API de YouTube mediante OAuth 2.0 con el permiso explícito del propietario del canal para subir y gestionar videos generados automáticamente. No recopilamos, almacenamos ni compartimos datos personales de terceros ni información financiera.

2. Uso de datos de la API de Google

El uso que hace Oráculo Diario de la información recibida a través de las APIs de Google se adhiere a la Política de Datos del Usuario de los Servicios de la API de Google, incluidos los requisitos de Uso Limitado.

3. Almacenamiento y Seguridad

Las credenciales de acceso (tokens de OAuth) se almacenan de forma segura y cifrada en los entornos de ejecución del proyecto y nunca son compartidas públicamente.

4. Contacto

Para cualquier consulta respecto a esta política de privacidad, puedes contactarnos a través del repositorio del proyecto.
